# Crop Research

A simple Chrome extension based on the Scrimba leads tracker project. Uses HTML, CSS, JavaScript, and localStorage.

## Chrome extension
1. Open `chrome://extensions`.
2. Turn on Developer mode.
3. Click Load unpacked and choose this folder.

## Vercel
Upload these files to a GitHub repository and import it into Vercel. Choose **Other** for Framework Preset, leave the build command empty, and deploy. No npm or Vite required.

## Using it
Enter a crop, choose Hydroponic or Soil-based, enter a research category, short note, and website URL. Click SAVE RESEARCH. SAVE TAB URL fills the URL field (on Vercel it can only fill the current website URL). DELETE ALL requires a double-click, as in the Scrimba project.

Research is saved in your browser's localStorage. It is not synced between the Vercel website and Chrome extension or across browsers.

## Four research entries for your assignment
Research and enter at least four genuine entries covering two crops. For example, research lettuce pH, lettuce lighting, tomato watering, and tomato soil nutrients. Include the actual source URL for each entry. Record a 15-second demo showing your saved entries and buttons. Submit screenshots/video, the GitHub link, and the Vercel URL yourself.
